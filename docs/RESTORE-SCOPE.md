# 変更範囲と復元対象（2026-11-10）

基準は最初の実装前 `3990d1b`。合意済みの変更と、その機能を動かすために必要な変更だけを残す。その他の表示・導線・挙動は基準に戻す。モックに描かれていないことを削除の理由にしない。

## 残す合意済みの変更

- 緑のいまカード、葉、通常タスクの開始・中断・完了、任意の一時メモと完了時削除、丸の子タスク進捗、記入済みメモの表示。
- イベントはいまカードで完了のみ。ルーティンの従来の計測・履歴・やり方を維持。
- 今日のいま＋直近予定、詳しい時間割のカードレイアウト・丸を避ける縦線・枠外の時刻未定チェック、実際の今日を中央に5日分。必要・必須・締切は初期に畳む。
- ②A：アイデアの一手入力と任意の詳細、追加のみ／作って始める。アイデアのプロジェクト化も維持。
- ③A：山画面の次の一手・空のプロジェクトへの一手追加と今日への開始。
- ⑤A：追加入口を右下へ、追加／保存の名称統一、指定されたタブ内アイコン。ボードの作成・読み込み案内は今回戻す対象外。
- 一時メモ・外部からの開始を正しく保存・引き渡す処理、互換性・同期処理、対応する検証。

## 元に戻す表示・導線

- ホームの横軸の「今日の流れ」：時間幅・スクロール・現在位置・睡眠／仕事・時間割への入口。
- 時間割の右端の候補メニュー、広い画面の候補パネルと調子フィルター。
- いまカードのプロジェクト色付き表示、候補の★・プロジェクト・理由／締切、元の候補並び。
- ルーティンの続きメモの独立した枠と全文。
- ホームの直近予定を簡潔な2行へ戻す。
- いまカードの元の寸法設定・行構成を基準にし、丸の進捗は元のカウンター行にまとめ、空のメモ行は作らず、許可された表示を保ったまま外形を照合する。固定比率を勝手に新設したり、内容を切り捨てたりしない。
- 山の次のキャンプ名・進捗、通過点なし／全完了案内、元の道のりへの誘導表示を戻し、合意した次の一手と併存させる。
- iPadの週は元の横軸実装を維持。＋用に増やした下部領域を撤去し、元の表の高さ・比率を戻す。iPhone週も同様。

## 元に戻す挙動

- 今日終了状態を開始要求で自動再開しない。既存の「再開する」での操作を維持し、通知停止状態を勝手に変えない。
- 通常のタブ復帰で強制的に先頭へ移動したり、時間割を閉じたりしない。
- タスクの時計は元の今日画面内の一時状態へ戻す。アイデア／ボードの明示した開始要求だけを一度引き渡す。
- 開始要求で無関係な編集・設定・ルーティン画面を一括終了しない。必要な作成画面の終了と今日への遷移だけに限定する。
