# 保留中の作業と、配布するときにやること

終わったら行を消すか `[x]` にする。新しく保留にしたものはここに足す。

## 配布（App Store・一般向けTestFlight）の前にやること

### 個人用の仕組みを外す・隠す
- [ ] 「設定とデータ → Claudeとの連携」を一般向けビルドでは隠す。この連携は本人のSupabase（`horme` プロジェクト）専用で、他の人はURLと鍵を持たないので使えない。見えると混乱のもとになり、審査でも質問されやすい
- [ ] 連携URLの鍵（`HORME_KEY`）を、配布の前に作り直す。開発中にチャットなどへ書いたことがあるため
- [ ] 他の人にもClaude連携を提供するなら、複数人向けに作り直す（一人ずつのログイン、データの分離、コネクタの人ごとの認証）。サービス運営になるので、費用・プライバシーポリシー・データを預かる責任を先に決める

### App Store Connectの準備
- [ ] 説明文、キーワード、スクリーンショット（iPhone・iPad）、サポートURL
- [ ] プライバシーポリシーのURL。データは端末と利用者自身のiCloudに保存し、開発者は受け取らないこと、通知は端末内で予約していることを書く
- [ ] App Privacy（データの収集）の回答：収集なし（Claude連携を隠す前提）
- [ ] 年齢レーティング、価格、配信地域
- [ ] 審査メモ：iCloud共有の試し方（Apple Accountが2つ要る）を書く

### 品質
- [ ] iCloud共有を、異なるApple Accountの実機2台で通しで確かめる（招待、参加、両方向の追加・完了・削除、機内モード中の変更、再起動後の送信、共有解除後のデータ保持）
- [ ] 通知の許可を、最初に説明してから頼む形にする（今は起動時にいきなり出る）
- [ ] VoiceOver・文字サイズ（アクセシビリティ）・ダークモードの確認
- [ ] Siriの言い方（日本語）が実際に通るかの確認
- [ ] 英語など他の言語に対応するか決める
