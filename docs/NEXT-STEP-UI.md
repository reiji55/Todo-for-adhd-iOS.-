# アイデア・ボードからの一手と時間割の調整（2026-11-10）

## アイデア

「タスクにする」は元のアイデアと最初の一手を基本表示にし、日付・空き時間・分割・プロジェクト・アイデア保持・詳細編集は任意の「詳しく決める」に置く。「作って始める」は保存成功後に今日のいまカードで開始、「タスクを追加」は追加のみ。元の本文・追記メモと既存のID継承は維持する。

アイデア詳細の「プロジェクトにする」は独立した入口として残す。名前だけで作れ、任意の到達点・期限・概要カード・アイデア保持を維持する。

## ボード

山の最初の画面に「次の一手」の実タスクを1件表示し、存在する一時メモも表示する。既存の候補規則をそのプロジェクト内へ限定し、子タスク・締切を考慮する。イベント・完了済み・未来の固定予定は今始める候補にしない。予定が先にあるときはその内容を開き、タスクがないときは「最初の一手を追加」から簡単な入力へ進む。

開始は今日の同じいまカードへつながり、別の実行画面を増やさない。普通のタスクの時計は元の今日画面内の一時状態を維持し、アイデア／ボードの開始要求だけを一度引き渡す。通常のタブ復帰で表示位置や開いている時間割を変えない。今日終了状態は自動再開しない。中断後の次回開始は0から。既存のルーティン計測・イベント日時は維持する。

## 操作

一覧の追加は右下の同じ大きさ・位置の＋へ。アイデアは付箋入力、ボードはプロジェクト／カードの選択を開く。タスク名は内容・編集、明示した「始める」は実行、チェックは完了、新規作成は「追加」、編集は「保存」を共通にする。子タスク・通過点など対象の明らかな局所的追加操作は維持する。

## 詳しい時間割

日付は実際の今日を中央に2日前～2日後の5枚を維持。「今日の時間割」とその中の時刻未定のタスクを基本表示し、今日までの締切・必須・これからの締切は件数を見せて初期は畳む。「今できそうなもの」は既存の右端メニュー（広い画面では候補パネル）と調子による絞り込みを維持し、画面下部へ移さない。前日からの残タスクの振り分けは既存の入口を維持する。

大きな外側のパネルを外して各カードを浮かせ、実行中の時間帯には淡い色と左端のアクセントを付ける。縦線は各行の丸・再生ボタンの前後で切り、内部を貫通させない。現在時刻の赤線は丸の位置からカード右端へ。時刻未定の丸も同じ縦軸に配置し、点線カードの外へ出す。子タスクの進み具合は丸と件数で表示する。完了・開始・詳細編集・通常メモ・続きメモの既存機能は維持する。

## 検証

TaskCoreのプロジェクト候補テストと既存の保存・移行・同期テスト、配布設定テストを実行する。UIテストではアイデアからの開始・プロジェクト化・新プロジェクトへの一手追加・ボードからの開始・＋の位置・折りたたみ・丸の軸・既存の中断とルーティンを操作し、実画面を確認する。テストのサンプルはDebug限定のメモリ上データを使う。

## 既存の表示・導線の復元（2026-11-10）

今日の最初の画面には、既存の「今日の流れ」の横軸カレンダーを残す。時間幅で予定を表示し、横スクロール、現在時刻、睡眠・仕事の時間、時間割への入口を維持する。いまカードと直近予定の表示とは役割が異なるため、縦型の予定一覧で置き換えない。

画面図に描かれていないことを既存表示や入口の削除・移動の根拠にしない。既存機能を維持したまま、明示されたデザイン変更の範囲に限定する。

復元対象と維持する合意事項の一覧は `docs/RESTORE-SCOPE.md` を参照。
