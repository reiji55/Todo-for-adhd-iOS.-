# 今日・いまカードの合意仕様（2026-11-10更新）

通常タスクへの着手を主操作にする。今日のホームは「いまの一手＋このあとの流れ＋既存の横軸の今日の流れ」、詳しい時間割は既存の時刻・終了時刻・現在線を残す小さなカード一覧とする。

## タスク

- 開始前は「始める」「入れ替える」。開始前の補助完了ボタンは置かない。
- 開始すると同じカード内で実行中・今回の経過時間・「中断する」「完了」に切り替わる。別シートに遷移しない。
- 中断は即時に未完了のまま開始前へ戻す。候補は自動で入れ替えない。次回の経過時間は0から。
- 中断直後に任意の「次はどこから？」入力と「残す」を出す。入力せず別の操作へ進める。
- 一時メモは `continuationNote` として通常メモ・AI依頼・旧 `resumeNote` と分離する。保存に失敗した場合は入力を残す。
- 対象タスクの完了時に一時メモを削除。完了の取り消しは既存の履歴からメモも復元する。親の一括完了・子からの親完了・編集画面での完了にも適用する。
- 子タスクがある場合、今取り組む子タスクを主題、親を補足として表示する。進捗は4件以下なら丸を並べ、多ければ丸いリング＋件数。開始・中断では進捗を増やさない。子タスクがなければ省略する。
- 負荷の3段階切り替え、実データのメモ、控えめな葉、少数の候補を維持。「2分」ボタン・架空の説明・候補の「すべて見る」は追加しない。

## カード配置の追加合意

- 緑の枠は従来の白いカードではなく、合意した緑の提案画像を基準に小さくする。同じ内容・通常文字サイズで、直前版の高さの約2/3を目安とする。
- タイトルは22pt相当、内側余白14pt、段間8pt。横幅とボタンの50pt操作領域は維持する。固定の高さや比率を設けず、大きい文字や記入済みメモに応じて伸びる。
- 子タスクの丸・リングと件数は親タスク名の横に置かず、本文・メモの下、操作ボタンの上の独立した行に置く。開始前・実行中で同じ位置を使う。
- 「ほかの候補」は緑の枠の下へ出す。候補の件数・並び・★・プロジェクト・理由／締切・選択操作は保持する。実行中に選べない従来の扱いも維持する。
- 横軸カレンダー、直近予定、時間割、週、山画面、保存・開始・中断・完了の処理はこの配置調整の対象に含めない。

## イベント・ルーティン

- イベントのいまカードは時刻・予定名・記入済みのメモ・「完了」。入れ替えや開始・進捗は置かない。完了は日時を変えず済んだ印を付け、取り消せる。
- ルーティンは既存の開始・計測中→集中画面を維持。前回の続き、やり方、通常メモ、任意の次回メモ、計測継続・中断・完了、日別記録を置き換えない。
- 睡眠・仕事など「時間を押さえるだけ」の扱いも維持。

## 時間割・タブ

- 日付は2日前・昨日・今日・明日・2日後の縦長5枚。実際の今日を常に中央に固定し、選択しても日付の並びを動かさない。
- 時刻未定・必須・締切・繰り越し・候補・編集・既存の完了操作を維持。候補は既存の右端メニュー／広い画面のパネルを維持する。
- 今日ホームの横軸カレンダーは、時間幅・横スクロール・現在時刻・睡眠／仕事の表示と時間割への入口を維持する。
- 今日ホームの予定概要は既存と同じ「見る・詳細を開く」動線。詳しい時間割の完了・ルーティン開始操作は縦線上にまとめ、目印を二重に置かない。
- 通常メモと前回の続きは存在するときだけ最大2行ずつ表示。全文はタイトルから既存の詳細画面へ。
- 5タブの並びとニューモーフィズムの外枠・浮いた中央ボタンを維持。中のアイコンだけレイヤー／カレンダー／太陽／電球／区画パネルにする。

## 確認

TaskCoreのテストで開始・中断後の一時メモ・再開時計・完了・復元・移行・同期・親子完了・ルーティンとの独立性を確認する。
`scripts/interface-tests.sh` は使い捨てCIチェックアウトにだけUIテストターゲットを追加し、専用シミュレーターで実際にボタン操作とライト／ダーク画面保存を行う。配布プロジェクトにはテストターゲットを追加しない。
